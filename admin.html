Where do I get an access key?
  1. Ask Pixrweb — we'll send you one, or:
  2. Sign in to GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → choose the website repository.
  4. Permissions → Repository permissions → Contents: Read and write. Everything else: no access.
  5. Generate, copy the key and paste it above.
